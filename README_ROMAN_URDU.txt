ARSAL BOOKS MANAGEMENT — ANDROID APK PROJECT
============================================

Yeh proper Android APK banane ka source project hai.

App ID: com.arsalbooks.management
Version: 3.1.0
Minimum Android: Android 7.0

Features:
- Mobile WebView app; internet ke baghair kaam karti hai
- Login, Books, Stock, Purchases, Sales, Accounts aur Reports
- JSON Backup Downloads/ArsalBooks folder mein save hota hai
- Restore Backup ke liye Android file picker
- Invoice ke liye Print / Save PDF window
- Data isi app ke private storage mein rehta hai

DEFAULT LOGIN
Admin: admin / 1234
Staff: staff / 1234

IMPORTANT
App uninstall karne se local records delete ho sakte hain. Uninstall ya mobile
change karne se pehle Settings & Backup se JSON backup zaroor download karein.

GitHub Actions workflow .github/workflows/build-apk.yml proper APK build karta hai.
